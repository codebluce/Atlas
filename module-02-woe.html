分箱 / WOE / IV / 单调性：风控建模最日常的手活

逻辑回归喜欢线性关系，但原始特征几乎从不听话——年龄和风险不是直线关系，类别变量没法直接乘系数。分箱+WOE就是把任何"不听话"的特征，捏成模型能用的样子。

01

先说痛点：原始特征直接扔进模型会怎样

逻辑回归本质是在做线性加权求和，它假设每个特征和"风险"之间是一条直线关系——但现实里几乎没有变量这么听话。

📈 一个类比 "年龄"和"违约风险"的关系，往往是一个浅浅的U型：太年轻（收入不稳定）风险高，中年（收入稳定、有资产）风险低，年纪太大（收入下降、健康支出增加）风险又略微回升。如果强行让逻辑回归拿"年龄"这个数字直接乘一个系数，它只能学出"年龄越大风险越低"或"越高"这一种单一方向的直线关系，U型的中间那段"由高到低再到高"的真实规律，直接建模是学不出来的。

除了非线性关系，原始特征还有几个直接入模的硬伤：

问题具体表现
类别变量没法乘系数"婚姻状况=已婚/未婚/离异"这种字符串，逻辑回归根本算不了
异常值/缺失值敏感年龄字段里混进一个"199岁"，会把线性拟合直接带偏
可解释性差系数×原始值，业务很难翻译成"这一条对客户到底意味着什么"
分箱 + WOE 一次性解决三个问题 把连续变量切成几段（分箱），把每一段的风险水平转换成一个叫 WOE 的数值——这样类别变量、连续变量统一变成同一种"证据强度"的度量，异常值和缺失值也能被单独分到自己的箱里处理，逻辑回归拿到的是一份"已经翻译好"的特征。这是本节要讲的核心手艺。
02

先搞清楚：分箱在做什么

分箱是特征工程的第一步，后面WOE、IV都建立在分箱结果之上。

分箱
Binning
把连续变量切成几段区间（比如年龄切成4段），或把类别变量的多个取值合并成几组，降低特征复杂度，同时让"风险随分箱变化"这件事变得可以观察、可以解释。
记忆点：分箱是把"一条曲线"拍扁成"几根柱子"
分箱方法
Binning Methods
等频分箱（每箱人数一样多）、等距分箱（每箱区间宽度一样）、卡方分箱/决策树分箱（有监督，按"能不能区分好坏"自动找最优切点）。业务上常用卡方/决策树分箱，因为它直接考虑了标签。
记忆点：有监督分箱通常比无监督分箱更贴合业务
分箱的两个硬性要求 每个分箱的样本量不能太少（业界经验：至少占总样本5%左右），否则这一箱的风险水平会被随机波动主导，不可信；分箱数量也不宜太多（常见4~8箱），箱太多会让WOE曲线变得不稳定，且会在第⑥节讲到的"单调性"上更容易出问题。
03

指标图鉴：4 个特征工程核心概念

① WOE 证据权重
Weight of Evidence
衡量一个分箱里，坏客户和好客户分布差异的方向与强度。WOE为正，这一箱坏客户偏多（风险高）；为负，好客户偏多（风险低）。
WOE = ln( (坏占比) / (好占比) )
看什么：正负方向 + 数值大小
② IV 信息价值
Information Value
把每个分箱的WOE加权求和，衡量整个变量的预测能力，是筛选入模特征的核心依据。
IV = Σ (坏占比−好占比) × WOE
看什么：IV越大，这个变量越有区分力
③ 单调性约束
Monotonicity
分箱后的WOE理应随分箱有序变化（比如查询次数越多WOE越高）。如果忽高忽低，说明这个特征和风险不是简单的单向关系。
WOE₁ ≤ WOE₂ ≤ … ≤ WOEₙ（或反向）
看什么：曲线是不是"一路涨"或"一路跌"
④ 特征稳定性 PSI
Population Stability Index
不止评分要监控PSI，入模前的候选特征本身也要检查跨时间窗口的分布是否稳定（详细算法见模块三）。
PSI = Σ(实际占比−预期占比)×ln(实际占比/预期占比)
看什么：IV再高，不稳定也不能用

06

非单调特征：U型分布该怎么处理

不是所有特征都像"申请次数"这么听话。用"居住时长"这个经典反例走一遍。

为什么非单调特征不能直接塞进逻辑回归 居住时长<1年的客户风险最高（刚搬来、不稳定），1~3年风险最低（安顿下来），3~5年风险又开始回升（可能是又要搬家的信号），5年以上重新走高——如果直接把WOE编码后的这个变量放进逻辑回归，模型只能学到一个单一方向的线性关系，会在中间某一段"学反"，对某些客户给出业务上讲不通的评分。

三种处理方式：

方法做法
①合并分箱把WOE相近的箱合并，强制让曲线变单调（可能会损失一些信息量）
②拆成虚拟变量拆成"是否<1年""是否>3年"这类0/1变量分别入模，让模型自己组合出U型效果
③换用树模型树模型能自动处理非线性关系，但会失去评分卡的可解释性（见模块一第④节的取舍）
单调性检查是入模前的必做动作 不要等模型上线后才发现某个特征"学反了"再回头查——分箱之后先画一遍WOE曲线，肉眼或程序检查单调性，是特征工程里最基础也最容易被跳过的一步。
07

建模阶段就要做的稳定性体检

IV告诉你"这个特征有没有用"，PSI告诉你"这个特征稳不稳"——两件事同等重要，但很多团队只做了前者。

🩺 怎么做 用两个不同时间窗口的样本（比如建模用的近12个月 vs 更早之前的12个月），对同一个候选特征分别算一次分布，再用模块三讲过的PSI公式对比这两份分布——如果PSI已经偏高，说明这个特征的分布本身随时间在变，即使当下IV很高，未来也大概率会像模块三案例里"近3个月申请次数"那样，成为模型衰退的导火索。

08

实战案例：一个特征从原始数据到入模的完整流程

1

原始数据：近3个月申请次数（连续整数，0~20+不等）

从征信报告衍生出的原始字段，取值分散，直接入模不可解释也不稳定。

分箱

用卡方分箱在10000人的训练样本上，找到[0,1]/[2,3]/[4,5]/[6,8]/[9,+)这5个切点，每箱样本量都在5%以上（最小的[9,+)箱有580人，占5.8%）。

计算WOE，检查单调性

第④节算出的WOE序列 −0.916 → −0.388 → 0.332 → 1.010 → 1.112，严格单调递增，通过检查。→ 不需要合并分箱或拆虚拟变量。

计算IV，通过初筛

IV=0.563，远高于0.1的主力特征门槛。→ 预测力确认足够强。

检查特征PSI，识别风险但不放弃

跨窗口PSI=0.18，落在"需要关注"区间。→ 团队决策：保留入模（IV太强不舍得丢），但标记为"高监控优先级特征"，纳入模块三的月度特征PSI监控清单。

WOE编码，交给逻辑回归

原始的"申请次数"字段被替换成WOE数值，进入模块一第⑤节的评分卡转换流程，最终变成"0次+15分/1~2次0分/3次以上−20分"这张具体的分箱得分表。
09

三个容易踩的坑

坑一 · 分箱切太细，样本量撑不住
为了让WOE曲线看起来更精细，把一个特征切成十几个箱，结果某些箱只有几十个样本——这种箱的WOE几乎就是随机噪音，换一批数据算出来的WOE可能完全不一样，甚至出现某箱全是好客户或全是坏客户导致WOE趋于正负无穷。每箱样本量至少占总量的5%左右，是业界的经验底线。
坑二 · 只看IV，不看特征PSI
IV高的特征天然更有吸引力，但正如第⑦节演示的，预测力和稳定性是两件独立的事。只用IV筛选、跳过PSI体检，等于把"未来会漂移的特征"提前混进了模型，模块三讲的衰退案例，根源往往就在这一步埋下的。
坑三 · 忽视单调性，硬把非单调特征塞进逻辑回归
第⑥节"居住时长"的U型WOE如果不处理直接入模，逻辑回归会被迫学出一个"平均化"的错误方向，对中间那段客群的评分完全不可信。分箱后先画WOE曲线看单调性，是不能省略的一步，哪怕看起来只是多花五分钟。

11

自测：检验一下是不是真的懂了

Q1. 为什么"年龄"这种连续变量不能直接乘一个回归系数入模？
查看解析
因为年龄和风险的关系往往不是一条直线（比如U型：太年轻和太年长风险都偏高，中年风险低），逻辑回归只能学出单一方向的线性关系，学不出这种非线性形态。分箱+WOE能把这种非线性关系转换成模型可以直接使用的形式。
Q2. WOE为正和为负分别代表什么？
查看解析
WOE为正，说明这一箱里坏客户占比相对更高（风险更高）；WOE为负，说明好客户占比相对更高（风险更低）。数值大小代表这种倾向的强弱程度。
Q3. 计算题：某分箱好客户占比25%，坏客户占比10%，求这一箱的WOE和IV贡献（提示：ln(0.10/0.25)=ln(0.4)≈−0.916）。
查看解析
WOE = ln(0.10/0.25) ≈ −0.916。IV贡献 = (0.10−0.25)×(−0.916) = (−0.15)×(−0.916) ≈ 0.137。
Q4. 一个特征IV=0.45，很强，但特征PSI=0.3，该怎么处理？
查看解析
不能只看IV就直接放心用。PSI=0.3已经超过"严重漂移"的阈值，说明这个特征的分布本身很不稳定，即使当下预测力强，也很可能像模块三案例一样，成为未来模型衰退的根源。应该结合业务判断是否入模：如果一定要用，需要纳入高优先级监控清单，并准备好一旦漂移触发时的应急预案（比如临时加规则）。
Q5. 分析题：一个特征分箱后WOE呈现"先升后降"的非单调形态，业务上你会怎么处理？
查看解析
三种思路：①合并分箱，把WOE相近的箱合并，强制让曲线单调（可能损失一些信息）；②拆成虚拟变量，把这个特征拆成几个0/1变量分别入模，让模型自己组合出非线性效果；③如果这种非线性关系对业务很重要、又不想损失信息，考虑换用树模型作为辅助/挑战者模型，但要接受可解释性下降的代价（见模块一第④节）。

本节小结

特征工程的四件套——分箱、WOE、IV、单调性检查——本质是在做同一件事：把任何一个原始特征，翻译成逻辑回归听得懂、业务看得懂、经得起时间检验的形式。IV回答"有没有用"，单调性回答"讲不讲得通"，特征PSI回答"稳不稳"，三个问题都要过一遍，少一个都可能在后面（模块一的建模、模块三的监控）留下隐患。

分箱是翻译，WOE是度量，IV是筛选，单调性和PSI是把关。
