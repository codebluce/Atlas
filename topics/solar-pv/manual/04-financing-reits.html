02

直租的两种形态：三方交易与四方交易

直租都是“租赁公司买设备、租给电站”，差别在于谁当出租人。模式一是租赁公司自己当出租人，模式二是它先设一家项目公司，由项目公司当出租人。

模式一：A 公司直接购买设备出租

出租人是 A 公司本体，设备所有权自始登记在 A 名下。流程是：A 向供应商支付设备款并取得所有权 → 设备直发电站现场验收 → A 与 B 签融资租赁合同，B 付租金 → 期满 B 支付象征性留购价，设备所有权转给 B。

模式二：A 公司设立 SPV 持有设备出租

A 先出资设立（全资或控股）SPV 并注资 → SPV 向供应商付款买设备 → SPV 与 B 签租赁合同、B 向 SPV 付租金 → SPV 以分红或还本付息把钱回流给 A → 期满由 SPV 把设备转给 B。项目风险封闭在 SPV 这一层，不直接传导到 A 母公司。

逐项对照：交易结构与法律关系

维度模式一：A 公司直租模式二：A 设 SPV 直租
交易主体三方：A（出租人）、B（承租人）、设备供应商；A 以自身名义参与全部交易四方：A（母公司）、SPV（出租人）、B、供应商；SPV 为独立法人签约主体
合同体系《设备买卖合同》（A—供应商）+《融资租赁合同》（A—B），另附担保/保险文件出资设立文件（A—SPV）+《设备买卖合同》（SPV—供应商）+《融资租赁合同》（SPV—B）
采购与付款A 直接向供应商付款，资金来自自有或自身融资A 以资本金/股东借款注入 SPV，由 SPV 付款，资金用途与项目一一对应
所有权归属自始归 A，登记在 A 名下；跨省多项目时属地登记繁琐归 SPV，可按项目逐个设立并就地登记确权，权属边界清晰
租金流B 直接向 A 付租金，路径短、层级少B → SPV 付租金，SPV 再以分红/还本付息回流 A
期满与退出B 付清留购价，所有权由 A 直接转给 B，闭环简单由 SPV 转给 B；也可通过转让 SPV 股权实现项目整体退出，处置更灵活

逐项对照：风险、报表与成本

维度模式一：A 公司直租模式二：A 设 SPV 直租
风险隔离无隔离。项目违约、设备瑕疵、电站收益不足等风险直接落在 A 身上有效隔离。风险封闭在 SPV，单一项目出险不直接追索 A 的其他资产
会计与报表租赁资产与对应负债都在 A 的报表上，占用 A 的杠杆空间与授信额度体现在 SPV 报表，A 按持股关系合并；便于按项目单独核算与管理
监管指标大额项目易推高单一客户集中度、关联度与杠杆率等指标以 SPV 承接，可缓释单一主体口径下的集中度压力（须符合监管对 SPV 的规范要求）
融资与再融资主要依赖 A 自身授信、保理或应收租金转让，结构空间有限SPV 可作为独立融资主体做项目融资、资产证券化，便于引入外部投资人
税务与成本交易层级少，增值税链条简洁，无额外主体设立与维护成本多一层主体，需承担设立、记账、年审、税务与资金归集成本
证券化前景缺乏股权结构安排，后续无法直接发行持有型不动产 ABS天然具备“股权 + 债权”结构，是后续打包证券化的标准载体
实务口径 90% 以上的直租采用“直接购买设备”模式；SPV 模式多用于投资大、期限长（8—12 年）、需要破产隔离或后续证券化的项目。换言之，要不要设 SPV，先问自己三年后想不想发 ABS。
03

怎么选：先看风险要不要隔离，再看成本划不划算

优先选模式一
A 公司直租
单笔金额不大；承租人资质良好、项目现金流清晰；追求审批快、落地快、少一层成本；A 的集中度与杠杆指标仍有余量。
快、省、简单
不缺额度、不图证券化，就别多设主体。
优先选模式二
SPV 直租
电站投资额大；多项目并行、需逐项隔离与单独核算；需在项目属地登记确权、就地纳税；计划引入外部投资人或后续资产证券化。
隔离、可退、可证券化
要发 ABS，一开始就得留好股权结构。

三条合规提示

  • SPV 设立要合规：需符合融资租赁公司监督管理相关规定，关注地方金融监管部门对 SPV 设立数量、注册地及业务范围的要求，避免单纯为规避集中度指标而设立。
  • 设备与不动产的权属要理清：发电设备附着于电站不动产，需提前确认设备所有权、抵押权与电站备案/并网主体（通常是 B）之间的关系，避免权属与收益权冲突。
  • 多一层主体要算得过账：须测算设立、记账、年审、税务与资金归集成本，确认风险隔离带来的收益能覆盖增量成本。
04

售后回租：一条倒过来的比例

行业里有一个非常直观的信号：直租和回租的比例，从 2024—2025 年的 7:3，翻转成了 2025 年至今的 3:7。

时期直租 : 回租原因
2024—2025 年新政前7 : 3新开工旺盛，租赁公司参与建设期
2025 年至今3 : 7新开工萎缩，投放转向存量债务置换

这个翻转说明什么？不是租赁公司不想做直租，而是新开工没了。直租对应“新建”，回租对应“置换”，比例反转等于行业从增量市场切换到存量市场。回租的本质就是价格战：替换银行项目贷或他家租赁，成本压到 3.3%—3.5%，期限 8—12 年。

保理与证券化谱系：先分清“股”和“债”

保理：电费与国补能不能分开？

  • 法律上可以分：已经进入国补目录、挂在报表上的“应收国补”，是真实存在的债权，可以与未来电费收费权分开保理。
  • 未来的国补很难分：未来国补的前提是“持续发电”，与电费收费权绑定，单独保理难度大。
  • 关键看原融资合同：如果银行/租赁公司已经质押了全部收费权（含国补），再保理就受限。
  • 风险定价：国补不会“灭失”，但会“拖延”（历史上 2—3 年，现在 1—1.5 年）。无追索保理必须按到账时间定价，有追索保理则看主体。

光伏 ABS：两种组包路径，四笔真实定价

在做 REITs 之前，多数租赁公司会先发一单 ABS 试水。光伏 ABS 的结构不复杂，难的是解决“资产 20 年、证券 3 年”的天然错配。

两种组包路径

路径资产构成适用主体
A · 混合资产包光伏与工程机械、通用设备等其他品类租赁资产共同入池业务结构多元的租赁公司
B · 整包光伏资产资产池全部或绝大部分由光伏租赁资产构成电力集团下属租赁公司，依托股东获得稳定的项目来源

核心矛盾：光伏电站运营期常在 20 年以上、设备租赁期长、现金流回收慢，与证券端短久期、低成本的需求存在天然错配。行业用两个办法缓解，各有代价。

办法一 · 差额支付承诺
把信用从资产抬到主体
由原始权益人或集团对优先级证券提供差额补足。
评级更高、票面更低
代价是资产难以真实出表。
办法二 · 3 年期含权
把久期压到 3 年内
优先级证券设置预期收益率调整选择权、回售/回购选择权，将期限控制在 3 年内。
降低融资成本
代价是承担回售与再融资的不确定性。

07

两种视角的拼图：债权 vs 权益

两场交流最大的价值，不是各自讲了多少知识点，而是同一件事被两种完全不同的职业视角拆开讲了一遍。

国泰海通（上午场）站在“债权人 + 产品结构”的角度，关心钱怎么放出去、怎么收回来、怎么证券化。财通资管（下午场）站在“产业链 + 投资人”的角度，关心资产从哪来、值多少钱、未来谁能接。

国泰海通：把电站当成一笔“有抵押的现金流”

  1. 业务形态随政策摆动：新政前直租为主（7:3），新政后回租为主（3:7）；不是租赁公司不想做直租，是新开工没了。
  2. 直租的抓手是“建成”：证照、批复、EPC、组件供应、并网，五件事决定项目能不能形成资产；早年央企租赁公司几乎零不良，靠的就是这套抓手 + 集团回购。
  3. 回租的本质是“置换”：替换银行项目贷或他家租赁，价格战打到底，成本 3.3%—3.5%，期限 8—12 年。
  4. 证券化是“退出”，不是“融资”：持有型不动产 ABS 的核心是“真实出售、破产隔离、平层、无主体兜底”，能不能发出去，取决于资产本身和投资人条款。
  5. 风控从“看建设”转向“看运营”：现在要判断电价、限电率、运维、主体，而不是只看可研。

财通资管：把电站当成“产业链末端的金融产品”

  1. 产业链是从沙子到组件：越上游越重、越集中、越周期；越下游越轻、越分散、越卷。
  2. 历史是四轮周期：欧洲补贴→国补→531→双碳；每一轮都有人暴富，也有人破产。
  3. 户用是“渠道 + 金融”生意：正泰靠低压电器经销商，家电系靠家电下乡网络；谁掌握村镇渠道，谁就赢。
  4. 136 号文把电价变成“股票市场”：白天低价、晚上高价、极端负电价；机制电量是“底仓”，市场化交易是“超额”。
  5. 退出靠 REITs，条款是艺术：业绩对赌、流动性支持、倾斜分配，三者既要让投资人安心，又不能让审计师认定为债。
关键问题债权视角权益视角综合结论
什么样的资产最安全有主体、有抵押、有账户监管有电价、有限电率、有收缴率主体 + 资产双保险，缺一不可
期限怎么匹配租赁 8—12 年，回租 3—8 年REITs 15—50 年，匹配资产寿命短钱做建设、长钱做持有
增信怎么设设备所有权、担保、差额补足业绩对赌、流动性支持、倾斜分配债权靠物权，权益靠条款
怎么退出回租置换、ABS、持有型 ABS机构间 REITs、公募 REITs、市场化处置REITs 是终点，租赁是起点
最大风险建成风险、承租人违约电价下行、限电、收缴率建设期看能力，运营期看数据
一句话总结 国泰海通告诉你“怎么把钱安全地放进去”，财通资管告诉你“这个资产未来值多少钱、怎么卖出去”。两者合起来，才是一条完整的“投—融—建—管—退”链条。

直租（模式二）
主体：四方。所有权：归 SPV。
优点：隔离、可出表、可证券化。代价：多一层成本。
怎么选
小额、快、额度够 → 模式一；大额、多项目、要证券化 → 模式二。
三条合规
SPV 设立合规；设备与不动产权属理清；多一层成本要算得过账。
回租
本质：债务置换。期限/成本：3—8 年，3%—3.5%。
比例翻转
新政前：直租 7 : 回租 3。
2025 至今：3 : 7。
ABS 组包
混合包：多元租赁公司。
整包：电力集团下属租赁。
两大缓解
差额支付（抬评级、难出表）；3 年含权（降成本、有回售风险）。
真实定价
优先级：1.80% / 2.06% / 2.10% / 3.35%，期限 0.76—10.83 年。

自测：检验一下是不是真的懂了

第 1 题 · 概念辨析

直租两种形态最本质的差别，是“多一层主体”还是“多一层风险隔离”？

查看解析
是风险隔离带来的结构能力。多设 SPV 只是手段，真正换来的是：单一项目出险不追索母公司、可按项目单独核算、以及具备发行持有型不动产 ABS 的股权结构。
第 2 题 · 定义复述

用一句话解释为什么“模式一直租”后续无法发行持有型不动产 ABS。

查看解析
ABS 需要把项目公司股权 + 债权一起装入专项计划，而模式一只有 A 对 B 的租赁债权和设备所有权，没有可转让的项目公司股权结构。
第 3 题 · 计算题

某 100MW 电站设备款 2.4 亿元，走 SPV 直租。若 SPV 注册资本 0.6 亿元、其余由 A 以股东借款注入，A 的出资结构大致是什么比例？

查看解析
资本金 0.6 亿、股东借款 1.8 亿，比例约 1:3。这种“股 + 债”的结构正是后续证券化的基础——专项计划受让股权的同时承接债权。
第 4 题 · 信号判读

看到一单光伏 ABS 优先级利率只有 1.80%，能不能判断“光伏资产很安全”？

查看解析
不能。1.80% 对应的是 0.76 年期限 + AAA 集团差额支付，本质是主体信用和短久期，不是资产本身的风险定价。
第 5 题 · 分析题

公司准备做第一单光伏租赁，计划三年后发 ABS。你会建议用哪种模式？还要提前确认哪两件事？

查看解析
建议模式二（SPV 直租）。提前确认：一是设备与电站不动产的权属/抵押关系是否冲突；二是当地金融监管对 SPV 设立数量与注册地的要求。

本节小结

融资工具是一条按生命周期拼接的链条：建设期直租、运营期回租与保理、成熟期 ABS 与 REITs。直租的两种形态看似只差一层壳，实际差的是风险隔离、报表占用和未来的证券化能力。ABS 能解决一部分期限错配，但代价是要么让主体兜底（难出表），要么把久期压到 3 年（有回售风险）。

建设用直租，置换用回租，盘活用保理，退出用 REITs。
