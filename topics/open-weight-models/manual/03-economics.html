痛点 · 千问、Kimi 和 MaaS：免费权重怎么变成四门生意？

免费权重后的四笔生意：从千问入口到 Kimi 授权

从仓库下载权重，只是商业落地的起点：GPU、推理服务、权限控制、业务数据清洗、评测、持续更新与安全治理都要花钱。

免费权重可以带来云、私有化、训练工具和托管授权收入。相关生意有四条收入路，第一是阿里千问一类开放模型为云计算、存储及数据库带来需求——模型免费，运行模型的云收费；第二是把模型部署到企业自有机房或私有云，提供定制、优化和维护；第三是微调、强化学习、数据评测等后训练平台；第四才是给 MaaS 或云服务商提供商业授权与认证。

第四条不是简单“对免费用户反悔”。Together AI、Fireworks 等托管方把别人的模型部署到自己的 GPU 上卖 API，许可证与官方合作可以让部署、版本、质量和标识更明确。

官方认证是一种商业合作，不自动代表所有托管商都交费。这种认证有点像“Intel Inside”，但并不意味着所有模型合作都采用同一规则；月之暗面 ARR 约 3 亿美元是一项尚待核对的年化指标，不是当年实收利润，须按计算日及合同收入核对。

年化收入不是当年已经到账的现金。月之暗面 ARR 约 3 亿美元是尚待对照披露的某时点年化运行口径，不等于已审计年度营收，也不能据此倒推云、部署、后训练和商业授权四条收入路各自的占比；托管平台与模型开发方往往并非同一收款主体。

经济逻辑是：开放权重先扩大可部署范围，再在云、私有化、训练工具或大规模转售环节收费。四条通道未必同时由一家模型公司掌控；云厂商、模型方和托管方的收入在供应链里还可能重叠，不能把所有人的营收加成一家公司“开源收入”。

私有部署和后训练卖的不是同一件东西。医疗、金融机构采购私有化服务时，可能付费给部署、调优、安全和长期支持；使用自有数据做微调或强化学习，则要付计算资源、评测和版本管理费用。Together AI、Fireworks AI 等托管商转售开放模型 API 时，商用许可、质量承诺与品牌认证仍取决于合同，不等于原模型的所有 API 收入归开发方。
