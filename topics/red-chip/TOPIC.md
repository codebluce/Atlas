# 红筹架构 · 专项学习手册

> 面向零基础读者；本手册用于建立概念框架，不提供个案法律、税务或投资意见。2026-09-24 更新。

## 定位

- 原型：概念/框架型，辅以流程和少量融资算术。
- 起点：[金杜研究 2026-09-20 文章](https://mp.weixin.qq.com/s/7GPB_f5J4hCYmhSX7X9zgA)。只借它提出的问题组织课程；不转载原文图表与长段落，不把市场观点改写成规则。
- 横向主线：认识结构 → 搭建 / 运营 → 上市路径 → 保留或拆除。
- 纵向主线：谁在上市 → 谁在持股 / 控制 → 钱和业务怎样跨境 → 哪些规则适用。
- 贯穿案例：虚构“云帆科技”的老周、老沈、远山资本；金额和比例在 `narrative.json`。任何真实法规数字与虚构案例严格分开。

## 风险与写作约束

1. 本领域时间敏感。提到监管新规时分别标注“生效法规 / 征求意见稿 / 市场观察 / 作者建议”，核对公布与实施日期。
2. 起点文章的“5.3%”是样本中红筹获备案企业占全部获备案企业的比例，不能称为红筹申请成功率；“三选二”不是法定门槛。
3. BVI、香港、WFOE 层并非必备；VIE 不保证控制权或外资准入合规；香港中间层不自动享有协定税率。
4. 保留已有 `narrative.json` 中教学案例比例；其中旧草稿的预提税/分红数字暂不纳入正文，须先单独复核税务适用条件。
5. 七篇已上线，全部可从主题页进入；以后新增章节再逐项同步目录状态。
