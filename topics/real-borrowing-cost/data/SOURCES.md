# 历史数据说明

- 两份 CSV 逐格转录用户 DailyDigest 的《中美企业实际借贷成本综合分析》2026-09-12 附录，范围 2020Q1—2026Q2（各 26 行）。
- 每列 % 为百分点单位的百分数；`approx_*` 是原报告里的“名义利率−同期物价同比”，不是某企业的真实贷款合同成本，也不是签约时预期实际利率。
- 原报告中国代理：金融机构一般贷款加权平均利率；美国：穆迪 Baa 债券收益率/Prime 报价。不同融资工具不能直接比较绝对水平。
- 2025Q4 美国 CPI 原报告缺一个月，CSV 中两处空白保持原状；不以插值填补。
- 仅算术复核通过，历史原始系列、更新修订和统计口径仍需分别向报告列明的人民银行/统计局、FRED 等来源查验；本仓库不对原始数据作 Wind 已核验声明。
