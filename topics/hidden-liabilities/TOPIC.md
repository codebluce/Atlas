# 表外融资与风险转移学习手册 · 课题规格

> 原型：concept-frame。四篇正文全部上线；只做教学和事实核查框架，不构成投资建议。

## 起点与边界

- 起点文件：DailyDigest/202609120023_消失的万亿债务深度分析报告.html（整理日期 2026-08-22）。只提炼论点，不复制原文全文或其图片。
- 原报告对真实公司交易、评级、现金流和养老金资金链的陈述尚未逐项核对监管申报；课程不据此指称某公司隐瞒债务。“表外”只描述列报位置，不代表经济风险消失，也不自动等于违规。
- 真实交易应逐案对照公司10-K/10-Q、财报租赁/担保/采购承诺附注、SPV协议、评级报告，并核对合并原则与适用会计准则；本册青藤云全部金额均为虚构教学数据。
- 横轴：现金流缺口→融资结构→信息披露→损失分配；纵轴：法律追索、会计合并、担保/租赁义务与最终出资人。
- 贯穿虚构案例：青藤云资金缺口 50亿元。假设明细见 `data/qingteng-case.csv` 及 `data/SOURCES.md`，只在教学图与示例使用；真实观察值逐项列日期、代码、来源。

## 延伸阅读与更新约束

可按“合同付款义务 → SPV/租赁负债 → 担保与残值 → 债权人 → 最终资金来源”画穿透图；合并和租赁的会计分类须结合当期财报及专业意见，不能按持股比例机械判定。

更新真实数据前先写取数日期、指标口径和权限状态；教学样本独立于真实层。状态以 `topic.json` 为准，跨章案例以 `narrative.json` 为准。运行 `python3 tools/check_handbook.py topics/hidden-liabilities` 校验。
