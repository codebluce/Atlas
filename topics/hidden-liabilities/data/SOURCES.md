# 青藤云案例数据说明

全部数值均为虚构教学假设，非报告里的任何真实公司交易或监管披露。

- 第1章：资金缺口 = 150−100 = 50 亿元。
- 第2章：资产回收 15、债务 50，担保限额 20；担保人最多补偿 min(50−15, 20) = 20 亿元。
- 第3章：名义租金 = 6×3 = 18 亿元；按每年末、5%折现的现值约 16.34 亿元；不要与 SPV 债务及担保上限相加。
- 第4章：利息 = 50×7% = 3.5 亿元；本息合计 6 亿元；初始和压力情景的 DSCR 分别是 6/6 = 1、4.5/6 = 0.75。

案例刻意忽略税费、运营费用、合同顺位及更多资金来源，仅供练习现金流与风险承担路径。
